Getting Started

  1. Ensure the drone battery voltage is > 10.8V.
  2. Follow the instructions in the Sensor Usage section of sensor specifications
  3. Connect to the drone using QGroundControl.
  4. Calibrate sensors using the ground station interface.
  5. Plug in the Nomad module and PS4 controller into the computer.
  6. Initiate takeoff and being monitoring sensor data in the dashboard.
  7. Automatically land when the flight is complete.
  8. Offload the SD card for further data analysis.
