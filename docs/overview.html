System Architecture

The RTRD platform integrates flight control, sensor acquisition, and data telemetry through a modular architecture. Each subsystem is designed for reliability and extendability.

Firmware & Communication

Firmware supports real-time telemetry over secure wireless links and logs sensor data to on-board storage. The API exposes commands for mission planning, calibration, and diagnostics.

Components

STM32F427ZGT6

  • 180MHz MCU with 2MB Flash and 256KB RAM.
  • Handles sensor data acquisition, processing, and communication.
  • Programmable using ST-Link V2.

    • Adafruit PA1010D

  • Mini GPS Module with < 2.5m position accuracy.
  • Supports NMEA output and PPS signal for precise timing.
  • Generates precise time measurements for data logging.

    • ELRS & Nomad Modules

  • 2.4 GHz wireless communication modules for telemetry and control.
  • Supports up to 1 km range with low latency.
  • Enables real-time data transfer and control using the ground station.

    • VL53L1CXV0FY

  • Time-of-Flight distance sensor with 4m measurement range.
  • Provides accurate altitude detection for automatic takeoff and landing.

    • BM1390GLV

  • Barometric pressure sensor with 0.1 hPa resolution.
  • Used for altitude estimation and atmospheric data logging.

    • Dual ICM-42670

  • 6-axis Inertial Measurement Unit (IMU) with high accuracy.
  • Enables autonomous landing and takeoff, stable flight.
  • Fused with barometer values for enhanced altitude estimation.

    • PMW3901

  • Optical flow sensor used to measure ground speed and control yaw.
  • Provides visual low-altitude odometry for position maintenance.

    • SD Micro

  • Enabes offline data-logging.
  • Interface for sensor configuration and data acquisition.
  • Compatible with FAT32 format.

    • FPV Camera (OV7670): 700TVL analog video streaming
    • Data Logger (SD Card): microSD storage with FAT32 support
    • Telemetry (ExpressLRS & Nomad Module): 2.4 GHz wireless transmit/receive at up to 1 km range

    Flight Control Firmware

    • Firmware is uploaded using the ST-Link V2 programmer and the SWO port on the main control board.
    • All firmware can be found in the "Firmware" directory of the project repository.
    • The IMU interface is specifically optimized without libraries to reduce latency and improve responsiveness.
    • Position and yaw estimates are made using the onboard GPS module.
    • Low-altitude odometry is provided by the optical flow sensor.
    • Altitude estimation is achieved through a fusion of barometer, ToF (if in range), and IMU data.
    • Pitch and roll measurements are derived from a fusion of the dual-IMU data.
    • Position hold functionality is enabled through a combination of GPS and optical flow sensor data.
    • Based on roll, pitch, and controller data, the flight controller adjusts the motor outputs using PID control algorithms.
    • Return-To-Home pathing is based on GPS coordinates and altitude data by lifting up 50 feet, using two GPS measurements to determine the angle to the home point, and flying in that direction until the home point is reached with a distance of less than 5 meters.
    • When auto-land is triggered, the drone descends at a controlled rate determined by altitude data until the ToF sensors detects an obstacle withint 0.5 meters, at which the motors are disarmed.
    • Sensor data is collected at the update rate set by the user and logged to the SD card.

    Maintenance & Updates

    Keep the current firmware updated and review logs after each flight to ensure correct sensor calibration.

    Keep the battery at a healthy voltage during storage (depends on battery type) and above 10.8V during operation.
